# Admin panel of Warehouse website
This is a simple application built with React, created purely for practicing React concepts. The project is an admin panel for an e-commerce website and includes features such as adding, deleting, editing, and searching.
For registration and login form I have used react-hook-form and react-query and I have used custom hook for using react-query. Also I have used yup for validation.
I have created a modal context for add and edit products that I have used it for both of them.

## Project Purpose
The main goal of this project was to practice React fundamentals and build a simple admin dashboard interface.

## Technologies Used
- React
- React router
- Axios
- React-query
- React-hook-form

## Features
- Add new products
- Edit existing products
- Delete products
- Search through products
- Simple and clean admin dashboard UI

## Getting Started
To run this project locally, follow these steps:

### Installation
```bash
git clone https://github.com/malotfi29/negar-lotfi_week19
cd warehouse
npm install
```
### Run backend
```bash
cd warehouse-api
npm start
```

### Run
```bash
npm run dev
```
